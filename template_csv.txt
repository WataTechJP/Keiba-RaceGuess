競走馬CSVを作ってDBに登録し、新規予想で投稿できるようにする手順

目的:
- CSVからRaceとHorseを登録する。
- モバイルアプリの「新規投稿」でレースを選び、予想投稿できる状態にする。
- pyenv側のPythonではなく、このプロジェクトのvenvを必ず使う。

前提:
- 作業場所は manage.py があるプロジェクトルート。

  cd ~/personal-projects/keiba_battle

- Djangoコマンドは必ず ./venv/bin/python で実行する。

  OK: ./venv/bin/python manage.py ...
  NG: python manage.py ...


1. CSVファイルを作る

方法A: レース名もCSVに書く

例: japanese_derby.csv

race_name,horse_name
日本ダービー,ライヒスアドラー
日本ダービー,マテンロウゲイル
日本ダービー,ケントン

方法B: CSVは馬名だけにして、実行時にレース名を指定する

例: japanese_derby.csv

horse_name
ライヒスアドラー
マテンロウゲイル
ケントン

注意:
- ヘッダー名は必ず horse_name にする。
- race_name をCSVに書かない場合は、実行時に --race-name を必ず付ける。
- CSVはUTF-8で保存する。
- CSVは manage.py と同じ階層に置くとわかりやすい。


2. CSVをDBに登録する

race_name列があるCSVの場合:

./venv/bin/python manage.py import_horses japanese_derby.csv

horse_name列だけのCSVの場合:

./venv/bin/python manage.py import_horses japanese_derby.csv --race-name "日本ダービー"

成功すると以下のように表示される。

✅ Horses imported successfully.


3. DBに登録されたか確認する

レース一覧を確認:

./venv/bin/python manage.py shell -c "from prediction.models import Race; print(list(Race.objects.order_by('id').values('id','name','date','location')))"

特定レースの馬数を確認:

./venv/bin/python manage.py shell -c "from prediction.models import Race, Horse; race=Race.objects.get(name='日本ダービー'); print(race.name, Horse.objects.filter(race=race).count())"

期待例:

日本ダービー 18


4. 新規投稿で使えるか確認する

バックエンドを起動する。

./venv/bin/python manage.py runserver 0.0.0.0:8000

Expoアプリを開き直す。

cd mobile
npm start

アプリの新規投稿画面で確認すること:
- レース選択に「日本ダービー」が出る。
- レース選択後に馬が表示される。
- 1着、2着、3着のどれか1頭以上を選ぶとPOSTできる。


5. よくある失敗

ModuleNotFoundError: No module named 'corsheaders'

原因:
- venvではなくpyenv側のPythonで実行している。

対処:

./venv/bin/python manage.py import_horses japanese_derby.csv --race-name "日本ダービー"


CSV must have a horse_name column.

原因:
- CSVのヘッダーが horse_name になっていない。

対処:
- 1行目を horse_name または race_name,horse_name にする。


CSV must have a race_name column or you must pass --race-name.

原因:
- CSVに race_name がなく、--race-name も指定していない。

対処:

./venv/bin/python manage.py import_horses japanese_derby.csv --race-name "日本ダービー"


新規投稿にレースが出ない

確認:
- バックエンドを再起動する。
- Expoアプリをリロードする。
- レース名が想定と違っていないかDBを確認する。

確認コマンド:

./venv/bin/python manage.py shell -c "from prediction.models import Race; print(list(Race.objects.order_by('id').values_list('name', flat=True)))"


6. 次回の最短手順

1. manage.py と同じ階層に CSV を置く。
2. 以下で登録する。

   ./venv/bin/python manage.py import_horses your_race.csv --race-name "レース名"

3. 以下で確認する。

   ./venv/bin/python manage.py shell -c "from prediction.models import Race, Horse; race=Race.objects.get(name='レース名'); print(race.name, Horse.objects.filter(race=race).count())"

4. バックエンドを以下で起動する。

   ./venv/bin/python manage.py runserver 0.0.0.0:8000

5. Expoアプリをリロードして、新規投稿からレースを選ぶ。
